Page tools

Nine ways to change a PDF, without a desktop application. Each one finishes in milliseconds.

Merge PDFs

Join two or more PDFs into one, in the order you select them.

Extract pages

Pull out the pages you want as a new PDF, or save each one separately as a ZIP.

Delete pages

Remove the pages you no longer want, keeping the rest in order.

Rotate pages

Fix sideways scans, or turn a single page the right way up.

Compress

Shrink a heavy PDF by re-encoding oversized images. Text stays untouched and selectable.

Watermark

Stamp faint diagonal text across every page — DRAFT, CONFIDENTIAL, your company name.

Page numbers

Add “Page 1 of 12” style numbering to every page.

Password protect

Encrypt with AES-256 and decide what the reader may do with the document.

Remove password

Save a protected PDF without its password, so it opens anywhere. You must know the password.

Every tool runs on this server, writes to a temporary folder, and deletes your file the moment the download finishes. Source code · Free software under the GNU AGPL v3 · No warranty
